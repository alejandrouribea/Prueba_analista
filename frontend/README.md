# Frontend — Conciliador de facturas y retenciones

Aplicación Angular 21 que consume la API de Python del conciliador.

```bash
npm install
npm start          # http://localhost:4200
npm run build      # build de producción en dist/
```

Requiere que el backend esté ejecutándose en `http://localhost:8000`.
La URL de la API se configura en `src/environments/environment.ts`.

> Las instrucciones completas de instalación, las reglas de negocio y las
> decisiones técnicas están en el **README de la raíz del proyecto**.
